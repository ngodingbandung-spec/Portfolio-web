# Portfolio Website Kekinian

Siap dibuka dan diedit menggunakan Acode atau Code Editor.

## Struktur
- index.html — struktur website
- style.css — desain dan responsive
- script.js — menu, animasi, dan filter portfolio
- assets/ — tempat foto/logo/project

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder di Acode / Code Editor.
3. Buka `index.html`.
4. Pilih Preview/Run.
5. Untuk mengganti foto, masukkan file ke folder `assets/`, lalu ubah bagian gambar pada `index.html`.

## Bagian yang bisa diedit
- Nama dan profesi
- Deskripsi About
- Skill dan persentase
- Project portfolio
- Layanan
- Email
- WhatsApp
- Instagram
- Statistik pengalaman/project/client
- Warna dan desain melalui `style.css`

Website dibuat tanpa Node.js, npm, database, atau framework sehingga ringan untuk diedit di HP.
